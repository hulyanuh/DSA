This repository contains implementations of fundamental Data Structures and Algorithms written in C.

### Topics Covered
- Array List
- Linked List
- Stack (Array & Linked List)
- Queue (Array & Linked List)
- Circular Doubly Linked List
- Bit Vector Set
- Open & Closed Hashing
- Priority Queue
- Heap Sort
- Binary Tree (BFS, DFS, Operations)

Each folder contains a standalone C program that demonstrates basic operations of the data structure.
